## Utilizzo per Marker e Icone Mappa
Questi asset rappresentano il materiale grezzo ad alta definizione e le favicon ufficiali (già scalate/ottimizzate per piccole risoluzioni dai team di design delle rispettive compagnie).

Possono essere utilizzati direttamente dallo script di composizione dei marker (`generate_assets.py`) o per il rendering nelle schede informative e nei filtri di selezione brand.
